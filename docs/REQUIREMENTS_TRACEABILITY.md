# Starter-to-Brief Traceability

| Approved requirement area | Starter support | Student-owned assessed work |
|---|---|---|
| Persistent deployed platform | Supabase/Vercel connection path | Stable assessed release, justification and operational reliability |
| Business identity and catalogue | Two clearly labelled demonstration records | Business need, identity, five categories, 25+ products and licensed media |
| Public/customer functions | Catalogue view and sign-in plumbing only | Pages, navigation, search/filtering, contact, full account journey, basket, checkout, orders, returns and reviews |
| Administrator functions | Secure profile role field only | Controlled role assignment, protected interface and product/customer/order operations |
| Inventory management | Non-negative stock constraint | Transaction logic, thresholds, status presentation and operational summaries |
| Security | Environment-variable pattern and initial RLS | Server validation, complete RLS/authorisation, vulnerability controls, security testing and evidence |
| Accessibility/usability | Responsive semantic baseline | Justified design, keyboard/screen-reader checks, accessible errors and evaluation |
| Testing | None supplied | Customer/admin journeys, permissions, validation, database behaviour and failure cases |
| AI-enabled extension | None supplied | Need, method/model, integration, tests, evaluation and responsible-practice analysis |
| Project evidence | Repository/document structure | Attributable commits, Planner, decisions, risks, tests, checkpoints and contribution records |

The approved assessment and project briefs remain authoritative. This table is implementation guidance and does not replace them.
